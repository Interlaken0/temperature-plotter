## Project Overview
**Temperature Plotter v1.1.0** - A real-time industrial temperature monitoring application built with Electron, React, and Node.js, featuring hardware abstraction through FFI integration with native DLL libraries, enhanced console utilities, and cross-platform compatibility improvements.

### v1.1.0 Key Enhancements
- **Console Utilities Module**: Professional colour-coded logging with ASCII-safe notation
- **Fahrenheit Support**: Dual-unit temperature display with pre-calculated conversions
- **Cross-Platform Encoding**: Fixed Windows PowerShell Unicode corruption issues
- **Dynamic Test Reporting**: JSON-based test summary generation
- **Enhanced Documentation**: 7-file professional documentation ecosystem
- **Hardware Mode Management**: Manual override and automatic mode switching
