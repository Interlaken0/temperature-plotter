# Screenshots Evidence

This folder contains visual evidence for the Temperature Plotter project.

## Structure

- **01-app-interface/** - Application UI and interface screenshots
- **02-code-evidence/** - Code quality and implementation evidence
- **03-testing-quality/** - Test execution and results
- **04-architecture/** - System design and architecture diagrams
- **05-documentation/** - Documentation quality and structure
- **app-running.png** - Main application interface screenshot

## Adding Screenshots

1. Save screenshots with descriptive names
2. Add to appropriate numbered subfolder
3. Update this README with brief description
4. Reference in project documentation as needed

## Naming Convention

Use kebab-case with descriptive prefixes:
- `ui-main-dashboard.png`
- `chart-temperature-plot.png`
- `code-coverage-report.png`
- `test-unit-results.png`
- `architecture-system-diagram.png`
- `docs-api-reference.png`
