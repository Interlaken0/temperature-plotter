# Analysis Artefacts - AMF Temperature Plotter

## Overview
Simplified analysis artefacts for the AMF Temperature Plotter industrial temperature monitoring application.

Core data model showing temperature readings and configuration entities stored in memory.

### Data Flow Diagram
System data flow from hardware sensors through processing to user interface and in-memory storage.

Functional requirements for Industrial Operators.

Development requirements organised by epics and sprints.

### Object Map
Component architecture showing React components, services, and in-memory data storage.

### Impact Map
Business goals connected to technical deliverables and user needs.

## Project Scope

### Core Features
- Real-time temperature monitoring
- Hardware/simulation mode switching
- Temperature threshold alerts
- Historical data analysis
- CSV export functionality
- Theme management

### User Roles
- Industrial Operator: Monitoring, data analysis, configuration, and hardware management

### Technical Stack
- React components for user interface
- KOFFI DLL for hardware communication
- In-memory ring buffer for data storage
- CSV export for data analysis

These artefacts provide a complete view of the system architecture and requirements for development and maintenance purposes.
