# Analysis Artefacts - AMF Temperature Plotter

## Overview
Simplified analysis artefacts for the AMF Temperature Plotter industrial temperature monitoring application.

## Documents

### Entity Relationship Diagram
Core data model showing temperature readings, hardware devices, alerts, and configuration entities.

### Data Flow Diagram
System data flow from hardware sensors through processing to user interface and storage.

### Use Cases
Functional requirements for Industrial Operators and System Administrators.

### User Stories
Development requirements organised by epics and sprints.

### Object Map
Component architecture showing React components, services, and data storage.

### Impact Map
Business goals connected to technical deliverables and user needs.

## Project Scope

### Core Features
- Real-time temperature monitoring
- Hardware/simulation mode switching
- Temperature threshold alerts
- Historical data analysis
- CSV export functionality
- System configuration management

### User Roles
- Industrial Operator: Monitoring and data analysis
- System Administrator: Configuration and hardware management

### Technical Stack
- React components for user interface
- KOFFI DLL for hardware communication
- SQLite for data storage
- CSV export for data analysis

These artefacts provide a complete view of the system architecture and requirements for development and maintenance purposes.
